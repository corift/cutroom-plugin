# Note → memory

A note bubble slides in and types the user's note; on the payoff word a Claude-orange "✓ saved to memory" chip pops under it.

```json
{"do": "note", "at": "note", "text": "make the captions bigger", "saved_at": "remembers"}
```

- For lines about feedback, notes or memory. The note text is a real-sounding instruction, under 30 characters.
- `saved` changes the chip, `y` (330) moves it. Typing sound, then a click.
- Code: `V.note`.
